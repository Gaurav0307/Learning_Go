# Important Go Commands

## Initialize Go Project

```bash
 go mod init <Package-Name>
```

### Example:

```bash
 go mod init phonebook
```

## Run Go Program

```bash
 go run .
```

Or

```bash
 go run main.go
```

## Create Build of Go Project

```bash
 go build -o <File-Name>
```

### Example:

Windows

```bash
 go build -o phonebook.exe
```

Linux

```bash
 go build -o phonebook
```
